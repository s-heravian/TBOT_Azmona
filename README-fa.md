# ربات تلگرامی آزمونا | Azmona Telegram Bot

[English Version](README.md)

آزمونا یک ربات تلگرامی نوشته شده با زبان PHP است که به معلمان کمک می‌کند تا آزمون‌ها و پرسش‌های آنلاین را به راحتی درون تلگرام مدیریت و برگزار کنند. این ربات قابلیت‌هایی مانند ردیابی زمان دانش‌آموزان، ثبت پاسخ‌ها و تولید کارنامه به صورت PDF را داراست.

## 🚀 نسخه 2.3.0 (جدید)
در این نسخه نوسازی کدهای ربات به بلوغ رسید و کاملاً با سیستم‌های مدرن هماهنگ شد:
- **مهاجرت به فریم‌ورک Nutgram**: کدهای تعامل با API تلگرام که قدیمی و منسوخ بودند، با فریم‌ورک قدرتمند Nutgram جایگزین شدند.
- **جایگزینی TCPDF با mPDF**: کتابخانه قدیمی و سنگین TCPDF که حدود ۳۲ مگابایت حجم داشت حذف شد و کتابخانه mPDF از طریق Composer جایگزین آن گردید. با این تغییر، ربات برای طراحی‌های مدرن HTML/CSS کارنامه‌ها در آینده کاملاً آماده است.
- **سازگاری کامل با PHP 8.4**: تمام ارورها، هشدارها (Warnings) و مشکلات سینتکس کدهای قدیمی (مثل خطای فراخوانی روی آرایه‌های Null یا کانفلیکت بسته شدن دیتابیس) برطرف شدند.
- **مدیریت وابستگی‌ها**: اکنون تمام کتابخانه‌های پروژه توسط Composer مدیریت می‌شوند.

### امکانات
- **مدیریت آزمون‌ها**: امکان ساخت و مدیریت درس‌ها و آزمون‌ها توسط معلم.
- **ردیابی زمان زنده**: نمایش زمان سپری شده‌ی هر دانش‌آموز در آزمون از طریق آپدیت دکمه‌های شیشه‌ای (Inline Keyboards).
- **تولید خودکار نتایج**: ساخت کارنامه PDF بسیار دقیق و راست‌چین با استفاده از کتابخانه‌ی `mPDF` و ارسال مستقیم در ربات.
- **پیکربندی امن**: مدیریت تنظیمات توسط فایل `.env` (جلوگیری از نشت اطلاعات حساس در سورس‌کد).
- **پشتیبانی از Cron Jobs**: استفاده از اسکریپت‌های کرون‌جاب جهت بروزرسانی‌های منظم و ارسال یادآوری.

### پیش‌نیازها
- **نسخه PHP 8.1 به بالا (PHP 8.4 توصیه می‌شود)**
- **کامپوزر (Composer)** برای نصب فریم‌ورک Nutgram
- سرور وب دارای گواهی SSL (مانند Apache، Nginx یا کنترل پنل aaPanel)
- پایگاه‌داده MySQL

### نصب و راه‌اندازی
۱. کدهای ربات را از گیت‌هاب کلون کنید:
   ```bash
   git clone <repository_url>
   cd TBOT_Azmona
   ```

۲. **نصب وابستگی‌ها (مهم):**
   برای نصب فریم‌ورک و کتابخانه‌ها دستور زیر را در سرور اجرا کنید:
   ```bash
   composer install --no-dev
   ```

۳. فایل پایگاه‌داده `db.sql` را در دیتابیس MySQL خود درون‌ریزی (Import) کنید.

۴. نام فایل `.env.example` را به `.env` تغییر داده و اطلاعات دیتابیس و توکن ربات خود را در آن وارد کنید:
   ```bash
   cp .env.example .env
   ```
