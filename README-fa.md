# ربات تلگرامی آزمونا | Azmona Telegram Bot

[English Version](README.md)

آزمونا یک ربات تلگرامی نوشته شده با زبان PHP است که به معلمان کمک می‌کند تا آزمون‌ها و پرسش‌های آنلاین را به راحتی درون تلگرام مدیریت و برگزار کنند. این ربات قابلیت‌هایی مانند ردیابی زمان دانش‌آموزان، ثبت پاسخ‌ها و تولید کارنامه به صورت PDF را داراست.

## 🚀 نسخه 2.2.0 (جدید)
در این نسخه تغییرات ساختاری عمده جهت ارتقای امنیت و مدیریت بهتر کدها انجام شده است:
- **معماری ماژولار**: کدهای اصلی ربات برای مدیریت پیام‌ها و کال‌بک‌ها به فایل‌های `bot.php`, `includes/message_handler.php` و `includes/callback_handler.php` تفکیک شدند.
- **ساماندهی فایل‌ها**: تمامی کتابخانه‌ها مانند `tcpdf` و توابع تاریخ شمسی به پوشه `includes/libs/` و فایل‌های کرون‌جاب به پوشه `includes/cron/` منتقل شدند.
- **ارتقاء امنیت**: پاکسازی کامل داده‌های حساس هاردکد شده (مثل توکن‌ها و شناسه‌های عددی ادمین) هم از کدهای فعلی و هم از کل تاریخچه Git. تمام تنظیمات حالا صرفاً از طریق فایل `.env` خوانده می‌شوند.
- **رفع باگ**: باگ‌های مهم مربوط به کاراکترهای اضافی (Backticks) که باعث ایجاد ارور سینتکس در PHP می‌شد به طور کامل در کل پروژه برطرف گردید.

### امکانات
- **مدیریت آزمون‌ها**: امکان ساخت و مدیریت درس‌ها و آزمون‌ها توسط معلم.
- **ردیابی زمان زنده**: نمایش زمان سپری شده‌ی هر دانش‌آموز در آزمون از طریق آپدیت دکمه‌های شیشه‌ای (Inline Keyboards).
- **تولید خودکار نتایج**: ساخت کارنامه PDF از نتایج آزمون با استفاده از کتابخانه‌ی `tcpdf` و ارسال مستقیم در ربات.
- **پیکربندی امن**: مدیریت تنظیمات توسط فایل `.env` (جلوگیری از نشت اطلاعات حساس در سورس‌کد).
- **پشتیبانی از Cron Jobs**: استفاده از اسکریپت‌های کرون‌جاب جهت بروزرسانی‌های منظم و ارسال یادآوری.

### نصب و راه‌اندازی
۱. ریپازیتوری را کلون کنید:
   ```bash
   git clone https://github.com/s-heravian/TBOT_Azmona.git
   ```
۲. یک کپی از فایل `.env.example` با نام `.env` بگیرید و اطلاعات مربوط به دیتابیس، توکن ربات و شناسه ادمین خود را در آن وارد کنید:
   ```bash
   cp .env.example .env
   ```
۳. وب‌هوک (Webhook) تلگرام ربات خود را روی مسیر فایل `bot.php` تنظیم کنید.
۴. کرون‌جاب‌های سرور خود را برای اجرای `includes/cron/cron10.php` (هر ۱۰ ثانیه) و `includes/cron/cronh.php` (هر ساعت) تنظیم کنید.
