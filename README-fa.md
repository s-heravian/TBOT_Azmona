# ربات تلگرامی آزمونا | Azmona Telegram Bot

[English Version](README.md)

آزمونا یک ربات تلگرامی نوشته شده با زبان PHP است که به معلمان کمک می‌کند تا آزمون‌ها و پرسش‌های آنلاین را به راحتی درون تلگرام مدیریت و برگزار کنند. این ربات قابلیت‌هایی مانند ردیابی زمان دانش‌آموزان، ثبت پاسخ‌ها و تولید کارنامه به صورت PDF را داراست.

### امکانات
- **مدیریت آزمون‌ها**: امکان ساخت و مدیریت درس‌ها و آزمون‌ها توسط معلم.
- **ردیابی زمان زنده**: نمایش زمان سپری شده‌ی هر دانش‌آموز در آزمون از طریق آپدیت دکمه‌های شیشه‌ای (Inline Keyboards).
- **تولید خودکار نتایج**: ساخت کارنامه PDF از نتایج آزمون با استفاده از کتابخانه‌ی `tcpdf` و ارسال مستقیم در ربات.
- **پیکربندی امن**: مدیریت تنظیمات توسط فایل `.env` (جلوگیری از نشت اطلاعات حساس مثل توکن ربات یا پسورد دیتابیس در سورس‌کد).
- **پشتیبانی از Cron Jobs**: استفاده از اسکریپت‌های `cron10.php` و `cronh.php` جهت بروزرسانی‌های منظم و ارسال یادآوری.

### نصب و راه‌اندازی
۱. ریپازیتوری را کلون کنید:
   ```bash
   git clone https://github.com/s-heravian/TBOT_Azmona.git
   ```
۲. یک کپی از فایل `.env.example` با نام `.env` بگیرید و اطلاعات مربوط به دیتابیس و توکن ربات خود را در آن وارد کنید:
   ```bash
   cp .env.example .env
   ```
۳. وب‌هوک (Webhook) تلگرام ربات خود را روی مسیر فایل `bot.php` تنظیم کنید.
۴. کرون‌جاب‌های سرور خود را برای اجرای `cron10.php` (هر ۱۰ ثانیه) و `cronh.php` (هر ساعت) تنظیم کنید.
